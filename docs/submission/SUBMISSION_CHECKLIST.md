# 제4회 스마트축산 AI 경진대회 제출 체크리스트

기준 문서: `제4회 스마트축산 AI 경진대회 변경 공고.hwp`

정리일: 2026년 8월 26일

## 1. 소스코드 제출 여부

변경 공고의 1차 접수 제출서류 목록에는 소스코드가 포함되어 있지 않다. 명시된
서류는 참가신청서, 부문별 제안서, 정보 확인·조회 동의서, 홍보 활용 동의서다.
따라서 GitHub 저장소나 코드 ZIP은 1차 이메일 접수의 필수 첨부물로 해석하지 않는다.

다만 다음 사유로 코드는 별도 검증자료로 준비한다.

- 알고리즘 부문 평가 중 `구현·분석`이 30점이다.
- 2차 전문가 검정에서 데이터와 추가정보 확인을 할 수 있다.
- 기술개발 과제의 최종결과는 데이터 구성·수집·분석과 알고리즘 적용 결과를 담은
  기술 소개서(PPT)다.

제출 이메일에는 공고에 명시된 서류만 첨부하고, GitHub 링크 또는 코드 ZIP은
운영기관이 요구하거나 팀이 구현 증빙으로 추가하기로 결정한 경우에만 제공한다.
제공할 때에도 원본 데이터, 학습 가중치, 로컬 절대경로와 비밀정보는 제외한다.

## 5. 본선 대비 별도 준비물

공고상 알고리즘 기술개발 과제 본선 발표는 10분이며, 데이터 구성·수집·분석을 통해
개발한 기술을 설명하는 기술 소개서(PPT)가 최종결과물이다. 다음 자료를 발표용으로
별도 준비한다.

- MSU 공식 Test 성능표와 혼동행렬
- `ch16`에 집중된 False Negative 오류 분석
- NESTLER 특징 그래프와 결측 처리 설명
- PIO 정적 밀도 특징과 육계·무사건라벨 한계 설명
- AI Hub 국내 산란계 YOLO 미세조정 성능과 분할 중복 제거 설명
- AI Hub 산란단계별 오류와 개체수 교정 필요성 설명
- Digital Twin 3개 시나리오 위험곡선
- 카메라별 통합 위험 타임라인
- 예측 Bounding Box 기반 NESTLER 영상 위험 기능시험과 무사건라벨 한계 설명
- 현재 구현과 현장데이터 확보 후 구현을 구분한 로드맵
- 기존 CCTV·Edge AI 연계 구성과 Shadow Mode 운영절차
